# 方法与已有结果的适用范围

本仓库把流水线分拣拆成两个层次：Masked PPO 选择任务和未来计划；规则控制器完成移动拦截、IK、轨迹检查以及真实双指接触抓取。BC 教师热启动和 PPO 阶段的教师辅助用于改善早期学习，PPO 本身仍依据物理轨迹回报更新。

默认任务是四台 Panda、两工位、两深料箱、0.2 m/s 恒速、双列随机来料，每列中心间距约 0.60±0.18 m，入场最小平面边缘间隙 0.08 m。每个评估回合请求 100 件。默认感知为 oracle，腕部相机关闭。

## r3 改动

下游近侧范围为 `0.045 <= side*y <= 0.080 m`。在相应侧向预测保持有效时，调度完成边界从 x=0.82 m 延至 x=0.88 m。0.06 m 在 0.2 m/s 下对应约 0.3 s；原始派工窗口右界仍是 0.82 m，夹持阶段的 0.90 m 硬停和路径检查仍保留。修复了上层预测截止时间无条件回退、导致这些机会仍被动作掩码排除的问题。

每个工位目前只有一个待执行软计划，两个工位的 22×22 个选择构成 484 个动作。两臂已在执行的动作可以在某些阶段重叠，但同站共享区互斥依然限制同时抓取。开放更丰富的并发需要相应计划表示、工位就绪预测和带时间的双臂路径检查；仅增加训练步数不会让 PPO 越过硬掩码。

## 历史固定权重实验

以下为整理公开仓库之前，以同一个旧 PPO checkpoint 比较原控制器和 r3 的结果，不是新默认配置重新训练所得。旧模型及完整本机实验日志未随源码发布，表格仅提供项目背景，不能作为下载后已经复现的成绩。

| 配对种子（来料 / 物体目录） | 原版成功 / 100 | r3 成功 / 100 |
| --- | ---: | ---: |
| 1020000 / 10201 | 89 | 90 |
| 1020001 / 10202 | 89 | 89 |
| 1020002 / 10203 | 85 | 85 |
| 1020003 / 10204 | 92 | 92 |
| 1050004 / 10405 | 85 | 86 |
| 1050005 / 10406 | 87 | 89 |
| 合计 | 527/600（87.83%） | 531/600（88.50%） |

吞吐为 33.75→34.03 件/分，后两臂成功数合计 247→249。双方均没有掉落、未完成物体或记录到的机器人/臂间碰撞。有限批次零碰撞不是任意轨迹或连续空间的安全证明。四组验证曾用于原模型选模，不能把全部六组都称为独立泛化测试。

外侧放料成本和外侧返回两项早期实验分别减少成功数，公开默认均关闭。当前收益较小，尚未达到 98%，也没有证明更快或变速流水线上的泛化能力。

## 从零训练与评估

`sequence_r3_fresh.json` 在已有 BC+PPO 训练结构上启用 r3。从零训练无需历史 checkpoint；这个具体预设尚未完成完整训练，不继承上表成绩。训练、验证和最终测试应使用不同的来料与物体目录种子。

评估应报告完整请求分母、漏件、掉落、未完成、碰撞、吞吐和分臂占用率。占用率包含处理、返回、等待和恢复，不能等同于有效产出。共享区“受阻且可见”统计只是 0.1 s 快照中的粗候选，不代表全部候选都可抓；当前也没有逐物体完整失败因果链。

此前在约 16 GB、无 swap 的机器上，并行评估以及回合切换的新旧环境短暂重叠曾导致 OOM。公开通用评估入口一次只跑一个回合；多种子测试请顺序运行独立进程。不要按逻辑 CPU 数量直接设置同等数量的物理环境。
