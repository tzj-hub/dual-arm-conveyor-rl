# 公开版验证记录

日期：2026-11-24。

本公开版从已完成 r3 固定权重实验的工程整理而来。核心物理、抓取与学习算法保持原实现；增加了可独立使用的训练预设、按训练元数据恢复场景的推理入口、测试 fixture、安装说明和许可证。未启动新训练，也没有为这份从零训练预设生成成绩。

已完成的检查：

- 配置、控制开关和通用模型入口共 83 项测试通过；从零训练入口的可迁移性与防覆盖另有 3 项测试通过，共 86 项。
- 训练预览在含空格的新目录、无 Python 第三方 site-packages 的解释器模式下可运行，不创建训练输出、不依赖旧模型。默认参数被真实训练 parser 和种子拆分校验接受。
- wheel 构建成功，包中含完整 71 个资产文件，包括 Panda XML、网格、LICENSE/NOTICE 和 MuJoCo 许可证。
- wheel 安装到独立临时目录后，从该目录导入代码，创建四臂环境、执行 5 次决策步并检查机器人状态有限，调度适配器提供 484 个动作。为控制检查开销，该安装检查使用 4 件物体、8 个池槽和较小料箱容量；它不是完整成功率测试，也没有更新策略权重。
- 记录的 MuJoCo、NumPy、SciPy、PyTorch 和 Pillow 版本已核实存在于公开 PyPI。
- 发布目录不含本机虚拟环境、绝对符号链接、训练日志、旧权重或视频；项目资源通过包内路径加载。

本地验证使用既有 Python 3.13.15 依赖环境，并将新 wheel 安装到隔离的包目录。没有在一台全新的机器上完整下载全部依赖，也没有对所有受支持的 Python、驱动和操作系统组合进行验证。CI 配置会检查预览、元数据和 wheel 构建，不会在 GitHub Actions 中训练模型。

历史 88.50% 成绩的条件和限制见 [方法与结果说明](METHODS_AND_RESULTS.md)。本记录不承诺新训练达到同一成功率或 98%。
